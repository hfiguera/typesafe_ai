# Upstream reference material

This directory contains downloaded TypeSafe AI documentation from
[docs.typesafe.ai](https://docs.typesafe.ai), using the index in
[llms.txt](llms.txt). The downloaded pages retain the upstream text, including
model comparisons and examples for its Python and JavaScript SDKs. Those claims
belong to the upstream documentation and do not establish this Elixir client's
performance. These reference files may lag the current upstream documentation.

For this library's documentation, see the [project README](../README.md),
[consumer guides](../guides/getting-started.md), and
[HexDocs](https://hexdocs.pm/typesafe_ai). This reference directory is excluded
from the Hex package and generated ExDoc pages.
